# STRAVA Triathlon Club

Modern Next.js landing page for a triathlon club.

## Run locally
1. Install Node.js 18.18+ (20+ recommended)
2. Open this folder in a terminal
3. Run `npm install`
4. Run `npm run dev`
5. Open http://localhost:3000

The current version uses the uploaded STRAVA club logo. Replace placeholder visual blocks with real club photography when ready.
